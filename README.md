The Sports Ground Booking System is a web-based Java application developed using JDBC, Servlets, JSP, and Oracle Database to manage sports ground reservations efficiently.
The system allows users to add new ground bookings, view individual booking details, and display all booking records stored in the database.
The application validates input data, automatically generates unique record IDs using an Oracle sequence, and ensures secure database interaction using PreparedStatement. 
It follows a layered architecture (Bean, DAO, Service, Servlet, Utility) to maintain clean code structure and separation of responsibilities.

Key Features

 ==> Add new ground booking

 ==> Automatically generate unique Record ID

 ==> View booking details by Team Name and Date

 ==> View all booking records

 ==> Store booking details securely in Oracle Database

 ==> Use JDBC PreparedStatement to prevent SQL injection

 ==> Clean layered architecture implementation
